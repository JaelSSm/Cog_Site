Attention Network Test (ANT) Attention Network Test (ANT)

Instrukció Instructions

A Figyelmi Hálózat Teszt segítségével elkülönítve vizsgálható a figyelmi rendszer három alapvető működése: az éberség fenntartása, a figyelem megfelelő helyre irányítása (orientáció) és a zavaró információk közötti konfliktus kezelése (végrehajtó kontroll). The Attention Network Test can be used to separately examine the three basic functions of the attention system: maintaining alertness, directing attention to the appropriate location (orientation), and managing conflict between distracting information (executive control).
